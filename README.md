## 게임 소개

두 공간으로 나뉜 연구소에서 4인이 협력해 탈출하는 공포 게임입니다.  
퍼즐 문제와 힌트가 서로 다른 공간에 배치되어 있어, 무전기 없이는 진행이 불가능한 구조입니다.  
무전을 사용할수록 크리처가 반응하는 위험이 커지는 딜레마가 핵심입니다.

|------|------|

## 게임 규칙

### 승리 / 패배 조건

| 상황 | 결과 |
|------|------|
| 전원 탈출 | 완전 성공 |
| 일부 탈출, 일부 사망 | 부분 성공 |
| 전원 사망, 한 공간 전원 사망 | 실패 |

### 역할 시스템
- **무전기 역할**: 무전기를 왼손에 소지, 공간 간 소통 담당
- **손전등 역할**: 손전등을 왼손에 소지, 어두운 환경 탐색 담당
- 역할은 게임 시작 시 랜덤 배정되며 변경 불가
- 떨어진 역할 아이템을 주웠을 때, 오른손에 소지되며 사용 가능

## 핵심 게임플레이

### 퍼즐 구조
- 1단계 퍼즐 완료 시 2단계 퍼즐 활성화 및 3단계 방 개방
- 2단계 퍼즐 완료 시 3단계 힌트 공개 (양쪽 구역 힌트를 합쳐 정답 완성)
- 3단계 퍼즐 완료 후 두 구역 동시 버튼 입력 시 카드키 지급

### 탈출 루트
- 2단계 퍼즐 전체 완료 시: 정문 + 옥상 (마스터키)
- 미완료 시: 정문 전용 (카드키)

### 크리처
- 플레이어 시야 감지, 목소리 감지, 발소리·오브젝트 조작음 감지에 반응
- 목소리 감지는 마이크 입력을 dBFS로 변환해 임계값과 비교하는 방식으로 동작

### 포획 & 구출
- 포획 시 아이템 즉시 드롭, 후유증 게이지 즉시 증가 후 매 초 1%씩 누적
- 게이지 100% 도달 시 사망
- 팀원이 4자리 비밀번호로 구출 구역 문을 열고 구출 가능

### 라디오
- 맵 곳곳에 배치된 라디오를 수리해 크리처를 특정 위치로 유인하는 미끼로 활용 가능
- 수리 과정에서도 크리처가 반응할 수 있음

### 관전 모드
- 사망 또는 탈출 시 관전 모드로 전환
- 마우스 클릭으로 관전 대상 변경 가능
- 관전 중인 플레이어가 듣는 사운드를 함께 들을 수 있음
- 관전자끼리 별도 채널로 소통 가능

## 담당 파트

### (이유정) — 게임 시스템 기획

### (안시우) — 크리처 / 맵

- 퍼즐 배치 및 진행도 동기화
- 크리처 FSM 및 동적 감각 시스템
- 플레이어 탈출 조건 및 판정
- 맵 제작과 오브젝트 배치 및 최적화
- 탈출 연출 및 트랜지션 

### (남의현) — 플레이어 / 퍼즐

- 이동, 상호작용 등 전반적인 플레이어 시스템
- 퍼즐 시스템 기획 및 개발
- Seed 기반 퍼즐 랜덤 배치
- 관전 카메라 등 전반적인 카메라 관리

### (이래호) — 네트워크 / 오디오 시스템 / 깃허브 관리

- Photon Fusion 2 세션 연결 및 대기실 관리
- Photon Voice 2 Interest Group 기반 공간 분리 소통 구조 설계
- 마이크 입력 dBFS 변환 파이프라인 및 크리처 AI 연동
- 게임 세션 종료 및 씬 간 결과 데이터 보존
- 화면 밝기 / 마이크 설정 시스템

### (김현수) — 사운드 / 모델링 / 아이템

- 플레이어, 크리처 모델링 및 애니메이션
- 아이템 멀티플레이 상태 동기화 및 시각 분리
- 미니게임 시스템
- 데이터 주도형 사운드 및 볼륨 제어
- 상호작용 외곽선 셰이더 렌더링
